Chess-Publisher v1.06.00-beta.94 — Common Base Recovery
Status: Windows TEST CANDIDATE
Parent: v1.06.00-beta.93

REAL-WORLD DEFECT
Unified SYNC could reach a safe conflict state but then show:
"The base revision is unavailable, so field-level conflict resolution cannot be performed safely."
This left older/upgraded tournaments without an actionable recovery path.

FIX
- Common base recovery trust order:
  1. stored schema-7 base fingerprint;
  2. current remote snapshot when its revision equals the stored base revision;
  3. immutable historical baseRevision;
  4. exact saved Cloud checksum matched to current remote or one unique immutable historical revision.
- Historical snapshot response is normalized safely.
- A recovered revision is used as the effective reconciliation base.
- Reset Tournament and Delete Round store explicit structural intent metadata.
- If no common base can be proved, field-level merge stays disabled.
- Instead, the user gets three safe choices:
  * Keep Desktop entire tournament
  * Keep Cloud entire tournament
  * Cancel
- Keep Desktop refetches the current Cloud snapshot before PUT and refuses if Cloud advanced.
- Keep Cloud performs no Cloud write and replaces only the local copy.
- Opening a different Cloud tournament no longer runs the legacy non-current reconciler first.
