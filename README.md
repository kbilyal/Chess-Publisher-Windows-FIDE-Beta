# Chess-Publisher Windows FIDE Beta

Dedicated Windows Desktop development/checkpoint repository for the Chess-Publisher FIDE/TEC beta line.

Current checkpoint: **v1.06.00-beta.71 — Windows Fluidity v2**.

This repository is **not** the public stable/release branch. Development here preserves protected tournament cores and creates an auditable checkpoint for every accepted Windows FIDE beta before the next TEC task begins.

Runtime release packages are retained in the ChessPublisher Releases Google Drive structure; source/checkpoint metadata, tests and editable Desktop code live here.
