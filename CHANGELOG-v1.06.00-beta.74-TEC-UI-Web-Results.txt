Implemented — Pairings workflow
- Result Entry / Pairing panel is a persistent right-side workspace; only the board table scrolls during normal desktop work.
- Pairings PDF export adds independent visibility controls for Board, White SNo., Black SNo., Title, Federation, Current points, Rating and FIDE ID while retaining existing presets/result-area/output controls.
- Starting List export adds practical column tick boxes for SNo., Title, Name, Rating, Federation, FIDE ID, Gender and Birth. Name remains mandatory.
- New Pairings action: ↓ Download Results.
- Download Results reads only result-state changes from the linked Web/Cloud tournament. It does not replace pairings, players, starting numbers or tournament settings.
- Web result matching is fail-closed by round + board/player identity; a pairing mismatch stops the operation.
- A plain blank Web result never clears a Desktop result.
- A different populated Desktop/Web result requires explicit confirmation before replacement.
- Standard results, forfeits, BYE/PAB result states, unusual OTB result metadata and explicit Adjourned state are preserved by the results-only download.
- Download Results never performs a Cloud Push and never changes the Desktop↔Web directional synchronization contract.
