BUG TEST RESULT
The extra SYNC stress suite initially exposed two real beta.86 gaps:
- Desktop and Web editing different Schedule rows caused a false conflict.
- Desktop and Web editing different fields of the same Schedule row caused a false conflict.
A third initial red case (Unicode rename) was confirmed to be a test assertion error: Unicode rename already round-tripped correctly; Cloud identity is transport/API metadata and is intentionally not embedded as cloudTournamentId in the portable tournament object.

ROOT CAUSE
`mergeThreeWay()` had stable array identities for players and live pairing boards, but no stable identity for `schedule.rows`. Therefore any two-sided Calendar rows change became an atomic array conflict.

FIX
`stableArrayMergeKey()` now recognizes Schedule rows by stable logical row number (`row.no`, with round/id fallback). Element-level merge is allowed only when base/local/remote have the same unique key sequence in the same order. Concurrent row insertion, deletion or reordering remains fail-closed.
